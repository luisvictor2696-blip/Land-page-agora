# Landing page Odonto Smiles
Página estática responsiva, sem instalação ou build JavaScript. A publicação em GitHub Pages copia apenas `index.html` e a pasta `landing` para o artefato público. Os arquivos de configuração anteriores do repositório são preservados, mas não são necessários para esta página.

## Edição
- Textos, oferta e unidades: `index.html`.
- Cores e layout: `landing/style.css`.
- Número e mensagens de WhatsApp: `landing/app.js` e atributos `data-message` do HTML.
- Logomarca original: `landing/logo.jpeg`.
- Fotografia de campanha: `landing/sorriso.webp` (modelo ilustrativa gerada por IA; não é paciente ou resultado clínico).

## Prévia local
Na raiz: `python3 -m http.server 8080`. Abra http://localhost:8080.
